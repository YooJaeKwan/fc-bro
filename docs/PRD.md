## 📄 Product Requirements Document (PRD)  
**Project Name**: 아마추어 축구팀 통합 관리 플랫폼  
**작성일**: 2025-08-06  
**작성자**: [총무 또는 기획자 이름]  
**버전**: v1.0  

### 1. 🎯 제품 개요  
아마추어 축구팀의 팀원 관리, 일정 관리, 참석률 분석, 실력 기반 팀 편성까지 한 번에 가능한 통합 관리 플랫폼을 구축한다. 주요 사용자는 팀 총무 및 팀원이며, 여러 팀이 동시에 사용할 수 있어야 한다.

### 2. 👥 주요 사용자  
| 사용자 유형 | 역할 및 권한 |
|------------|--------------|
| 총무(관리자) | 팀 생성 및 관리, 팀원 등록 및 데이터 수정, 일정 등록, 팀 구성 조정 |
| 팀원(일반) | 일정 참석 투표, 프로필 확인, 개인 정보 확인 |

### 3. 🔑 핵심 기능 요약  

| 분류 | 기능명 | 설명 |
|------|--------|------|
| **사용자 관리** | SNS 로그인 | 카카오톡 계정 연동 (프로필 사진, 이메일 자동 등록) |
| | 총무에 의한 선수 정보 관리 | 이름, 포지션, 평가 점수 등 입력 및 수정 |
| **팀원 관리** | 기본/세부 포지션 등록 | 예: 수비수 > 오른쪽 풀백, 왼쪽 센터백 등 |
| | 주/부 포지션 분리 | 주 포지션 1개 + 부 포지션 여러 개 설정 |
| | 평가 항목 구성 | 예: 속도, 패스, 수비 능력 (사용자 정의 항목 허용) |
| | 종합 평점 계산 | 수치 평가 기준을 평균 내서 실력 점수 산정 |
| **팀 자동 편성** | 팀 구성 알고리즘 | 포지션 균형 + 종합 평점 평균 기준으로 팀 자동 배정 |
| **일정 관리** | 일정 등록 | 날짜, 시간, 장소, 집합 시간, 쿼터 시간 등 입력 |
| | 참석 투표 | 팀원들이 해당 일정 참석 여부 체크 |
| | 자동 팀 편성 연동 | 참석자에 한해 팀 자동 구성 활성화 |
| **출석 관리** | 참석률 통계 | 일정 별 참석 여부 누적 저장 및 연도별 퍼센티지 분석 |
| | 미참여자 정리 기준 제안 | 참석률 낮은 팀원 파악 후 정리 권고 |
| **매치 기록 관리** | 경기 등록 | 득점, 어시스트, 출전 시간 입력 가능 |
| | 누적 경기 통계 | 선수별 기록 데이터 누적 집계 (선택 기능) |
| **멀티 팀 지원** | 팀 단위 계정 | 한 계정 내 여러 팀 운영 가능 |
| | 팀별 총무 설정 | 각 팀마다 총무 등록과 설정 가능 |

### 4. 📊 데이터 구조 개요 (Simplified)

| 테이블 | 주요 필드 |
|--------|------------|
| Users  | id, name, email, kakao_id, role (총무/팀원), team_id |
| Teams  | id, name, emblem, 관리자 id |
| Players | id, user_id, main_position, sub_positions[], 평점 요소들 |
| Schedules | id, team_id, date, location, status, 참석자 리스트 |
| Attendance | player_id, schedule_id, 출석 여부 |
| MatchStats | schedule_id, player_id, goal, assist, time_played |

### 5. 📌 우선순위 (MVP 기준)

| 우선순위 | 기능 | 이유 |
|----------|-------|------|
| 🎯 필수 | 팀 생성 / 팀원 등록 / 일정 등록 / 참석 투표 | 서비스의 핵심 골격 |
| 🎯 필수 | 종합 평가 항목 설정 및 팀 자동 편성 | 평등한 매치 편성 목적 |
| ✅ 추천 | 참석률 보기 및 기록 | 지속적인 관리 기능 |
| ✅ 추천 | 경기 기록 입력 (득점/어시) | 팀원 동기 부여 요소 |
| 🚀 확장 | 누적 통계 자동 시각화 / 랭킹 시스템 | 사용자 만족도 증가 |
| 🚀 확장 | 팀원 개인 프로필 공개 설정 | 프라이버시 고려 |

### 6. 🎨 향후 UI/UX 제안

- **대시보드 형태 홈 화면**: 참석률, 다음 경기 일정, 최근 경기 요약 등의 정보 표시
- **팀원 관리화면**: 포지션과 평점, 기본 프로필 한눈에 보기  
- **일정 카드 방식 UI**: 각 일정별 참석률, 경기 결과, 팀 구성 보기  
- **인터랙티브 팀 구성 인터페이스**: 드래그 앤 드롭 기반 수동 편성 가능

### 7. 🛠️ 기술 스택 제안 (선택사항)
